# Incentives Ledger prototype

A standalone React + Vite proof-of-concept for a fictional publication called
Incentives Ledger. It demonstrates roster navigation, actor dossiers, source quality
tracking, relationship context, methodology, and explicit AI audit logging.

All seed data is fictional and intentionally avoids real people, organizations,
and current events.

## Run locally

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 4174
```

## Test and build

From the repository root, use the shared CI script:

```bash
bash scripts/ci-test.sh
```
